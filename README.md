# Мій перший HTML-сайт

Навчальний мінісайт, створений у межах практичної роботи №3
з дисципліни «Створення Web-сайтів (Front-end)».

## Реалізовано

- три HTML-сторінки зі спільною навігацією;
- семантична структура HTML5;
- заголовки, абзаци, списки, зображення і таблиця;
- контактна форма з HTML5-валідацією;
- відео та аудіо з декількома джерелами;
- проста інтерактивність на JavaScript;
- адаптивне оформлення за допомогою CSS.

## Структура проєкту

- `index.html` — головна сторінка;
- `pages/about.html` — сторінка «Про мене»;
- `pages/contact.html` — сторінка «Контакти»;
- `assets/img` — зображення;
- `assets/media` — відео та аудіо;
- `style.css` — оформлення сайту;
- `app.js` — інтерактивність.

## Як запустити

1. Завантажити або клонувати репозиторій.
2. Відкрити файл `index.html` у браузері.
