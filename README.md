# Інтерактивний HTML CSS JavaScript мінісайт

Навчальний адаптивний мінісайт, створений у межах практичних робіт з дисципліни «Створення Web-сайтів (Front-end)».

## Реалізовано

- три основні HTML-сторінки та сторінка каталогу;
- семантична структура HTML5;
- адаптивне оформлення за допомогою CSS;
- мобільне меню;
- перемикання світлої та темної теми;
- збереження теми в localStorage;
- кнопка повернення вгору;
- автоматичне відображення поточного року;
- FAQ-акордеон;
- пошук і фільтрація рядків таблиці;
- модальні вікна;
- JavaScript-валідація контактної форми;
- лічильник символів повідомлення;
- збереження чернетки форми в localStorage;
- обробка форми через FormData;
- відображення повідомлення про успішну обробку даних.

## Каталог вебкурсів

У практичній роботі №9–10 реалізовано:

- локальний JSON-файл із даними курсів;
- асинхронне завантаження даних через fetch;
- використання async await і try catch;
- стани завантаження, помилки та порожнього результату;
- динамічне створення карток курсів;
- пошук курсів у реальному часі;
- фільтрацію за категоріями;
- сортування за назвою, рейтингом і тривалістю;
- кнопку «Показати ще»;
- перегляд деталей курсу в модальному вікні;
- додавання курсів в обране;
- збереження обраного в localStorage.

## Структура проєкту

- `index.html` — головна сторінка;
- `pages/about.html` — сторінка «Про мене»;
- `pages/contact.html` — сторінка «Контакти»;
- `pages/catalog.html` — каталог вебкурсів;
- `assets/img` — зображення;
- `assets/media` — відео та аудіо;
- `data/items.json` — дані каталогу;
- `styles/style.css` — основні стилі;
- `styles/responsive.css` — адаптивні стилі;
- `js/main.js` — загальна JavaScript-логіка;
- `js/catalog.js` — логіка каталогу;
- `screenshots` — скріншоти роботи сайту.

## Як запустити

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту у Visual Studio Code.
3. Встановити розширення Live Server.
4. Натиснути правою кнопкою на `pages/catalog.html`.
5. Вибрати `Open with Live Server`.

Пряме відкриття HTML-файлу без локального сервера не використовується, оскільки дані каталогу завантажуються через fetch.
