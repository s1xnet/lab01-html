# Мій перший HTML-сайт

Навчальний багатосторінковий сайт, оформлений у межах практичної роботи №5–6 з дисципліни «Створення Web-сайтів (Front-end)».

## Реалізовано

- три HTML-сторінки зі спільним дизайном і навігацією;
- зовнішні файли стилів `style.css` і `responsive.css`;
- оформлення заголовків, тексту, списків, зображень і таблиці;
- стилізація відео, аудіо та контактної форми;
- Flexbox для навігації та медіаблоків;
- стани `hover` і `focus`;
- адаптація сайту для мобільних пристроїв за допомогою media query.

## Структура проєкту

- `index.html` — головна сторінка;
- `pages/about.html` — сторінка «Про мене»;
- `pages/contact.html` — сторінка «Контакти»;
- `assets/img` — зображення;
- `assets/media` — відео та аудіо;
- `styles/style.css` — основні стилі сайту;
- `styles/responsive.css` — адаптивні стилі;
- `screenshots` — скріншоти desktop і mobile версій;
- `app.js` — інтерактивність.

## Як запустити

1. Завантажити або клонувати репозиторій.
2. Відкрити файл `index.html` у браузері.
